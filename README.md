A 1024 by 1024 newspaper page of Tuesday 17 November 2026: forty stories across six continents, twelve of them drawn as original flat icons, plus a pin map and a same-day list. main.ts copies the palette PNG; the page is drawn from data/stories.json by build/render.mjs and packed by build/pack.py.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
